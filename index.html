Petunjuk penggunaan

Untuk dekripsi, gunakan algoritma dan kunci yang sama. Jika menyalin hasil Base64, pilih format input Base64. Huruf besar dan kecil pada Base64 tidak boleh diubah.

Gunakan Extended Vigenere atau Super Enkripsi untuk file biner. Unduhan berisi byte hasil cipher. Saat dekripsi, akhiran .dat dilepas dari nama file. Nama dan ekstensi hasil dapat diubah sebelum diunduh.

Playfair menggabungkan J ke I dan menyisipkan X atau Q. Hill menambah X untuk pesan ganjil. Huruf sisipan tetap ada setelah dekripsi.
